## 1–2. 進度系統：由「外連入口」改為**直接接駁**

**背景**：原本嘅做法係喺執委系統開一條帶身份嘅 VSBADGE 連結（`from=portal&ymis=…`）。
VSBADGE v3.1 已加咗伺服器端驗證（`api/portal.js`：要對得上旅團登記嘅 `portalOrigin`／`portalRoles`），
所以未登記就直接貼連結會出現 `referer_mismatch`。

**團長指示**：唔要外連，要喺執委系統內**直接讀 VSBADGE**，而且可以**直接勾進度**。

**實作**：

| 檔案 | 做咩 |
| --- | --- |
| `api/progress.js`（新） | 同源 POST 轉發層：`load`（讀）／`save`（勾／取消）／`saveOtherBadge`（其他獎章）／`items`（考核項目定義）。只准 `script.google.com/…/exec`（擋 open proxy）、payload ≤ 1 MB、上游 45 秒逾時、log 只記 metadata（唔記 API Key、唔記完整後端網址） |
| `api/_registry.js` | 新增 `getProgressRegistryEntry(id)`：`TROOP_<id>_PROGRESSBACKEND` / `_PROGRESSAPIKEY` / `_PROGRESSFRONT` / `_PROGRESSFRONTURL`（設咗就由伺服器端提供，前端可以完全唔填） |
| `assets/js/lib/progress.js`（新） | 前端客戶端：`progressCfg` / `setProgressCfg`（存喺 `profile.progress.backend`）、`loadRemote` / `loadItems` / `saveTicks` / `saveOtherBadges` / `testConnection`，同埋配對工具（`flattenItems`、`summarizeRemote`、`memberDetail`、`matchLocalMember`） |
| `assets/js/views/progress.js`（重寫） | 分頁：**總覽**（逐個獎章完成度）／**成員進度**（逐個人）／**勾選進度**（直接勾／取消、可全勾全清、可還原、填日期）／**設定**（貼 `/exec` ＋ API Key、測試連線、舊入口連結保留喺最底） |

**旅團自己設定**（唔使管理員改 Vercel 設定）：VSBADGE 選單「顯示 API Key」複製 API Key ＋
複製 Apps Script 網頁應用程式 `/exec` 網址 → 喺「進度 → 設定」填 → 測試連線。
**API Key＝執委身份**：有 Key 就可以讀同勾；寫入嘅係 VSBADGE 用緊嘅同一個 Google Sheet。

> 讀寫需要伺服器端：Vercel 部署自動有 `/api/progress`；本機用 `npm run dev`（純靜態伺服器冇 API，進度會停用）。

介面所有顯示名（旅團閘、側邊欄、主頁 hero、頁腳、查詢權限表、申請接入對話框、教學、README、部署指南）

以免同 VSBADGE 共用嘅收件匣同總表分頁對唔上。

## 4. 領袖免收團費

`model.js` 新增 `feeExempt(member)`（`identity === 'leader'` 或 `member.feeExempt === true`）。
`feeGrid()` / `feeStats()` / `overdueFees()` / 首頁提示全部跳過免收嘅人；團費頁會列出「領袖免收團費」名單。
個人備註可以逐個開 `feeExempt`（例如榮譽會員）。

## 5. 財政年度報告：上年度結餘**唔再混入收入**

* 報告分四段：**上年度結餘（期初，唔計入收入）** → **本年度收入** → **本年度支出** → **本年度淨額**
* 期末結餘＝期初結餘 ＋ 收入 − 支出（每段獨立小計，唔會相加埋）
* 兩條數（旅年度 / 童軍年度）各自標明「上年度結餘（期初，唔計入收入）」
* Word／PDF 輸出同畫面一致

## 6. 帳目月份：冇紀錄嘅月份都揀得到

按月檢視嘅月份選擇器列出**全年 12 個月**，每項標示筆數或者「冇紀錄」（唔會再因為冇資料而消失）。

## 7. 新增「過往紀錄」分頁

「財務 → 過往紀錄」：**先揀年度 → 再揀月份**（12 個月＋全年），顯示期初結餘、該月收入／支出／淨額、
逐筆清單；可以一鍵跳返本年度同一個月。

## 8. 「帳目」分頁＝本年度

「帳目」只顯示本年度（依 `settings.fiscalYearStartMonth` 計），兩種檢視：
**總覽**（12 個月統計表，包括冇紀錄嘅月份）同**按月**（逐筆清單）。匯出／列印只覆蓋本年度。
上年度或更早嘅資料一律去「過往紀錄」。

## 9. 「表格」分頁移除，改為每頁自己改欄位

* 側邊欄**冇咗「表格」**；表頭亦冇咗相關按鈕
* 每個模組頁右上新增「**欄位**」掣：帳目（財務）／物資／借用／團員／通告／會議 ——
  改名、加、刪、改類型、必填、隱藏、排序、還原（同原本表格設計一樣，只係搬去該頁）
* **插入自己嘅 Sheet**、**總表同步**、**儲存用量／備份**搬去「**帳號與系統 → 資料管理（表格與同步（進階））**」
* 深層連結仍然有效（`#/tables/sync` 等），方便舊書籤
