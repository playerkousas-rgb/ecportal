## 三條漏洞（本身係獨立嘅，全部封咗）

清走靜態檔**唔夠**，因為仲有兩條後路會令新旅團見返 82 旅：

| # | 位置 | 本來會點 | 而家 |
|---|---|---|---|
| 1 | `data/units/0082/*.json` | 開機種落每部機 | **已刪** |
| 2 | `assets/js/lib/units.js` 嘅 `BUILTIN` | Registry 一讀唔到，就 fallback 去硬寫喺程式碼嘅 82 旅（連 `dataPath`）→ 任何訪客都會變成「82 旅」 | **清空**（`units: {}`） |
| 3 | `defaultUnitCode()` 嘅 `|| '0082'` | 揀唔到旅團就默認當你係 82 旅 | **改成 `''`** |

`data/units.json` 亦重寫過：`defaultUnit: ""`、`units: {}`、拆走頂層共用 `backend`
（呢個共用欄以前會令**未登記旅團都寫得入 82 旅張 Sheet**）。

## ⚠️ 仲要做一步：清後端 Google Sheet

程式碼層面清乾淨咗，但係**後端張 Sheet 仲有資料**。
如果唔清，你一登入，系統會自動由後端拉返成份舊資料落嚟（因為本機係空嘅）。

### 步驟

1. 開你張 Google Sheet
2. 撳去 **「資料庫」** 分頁
3. **揀晒所有 row（除咗第 1 行標題）→ 右擊 → 刪除**
4. 儲存（Google Sheet 自動儲存）

做完之後再登入，就會係真真正正嘅空白系統。

> 如果你想**保留**張 Sheet 嘅資料做備份，唔好清，改為：
> 檔案 → 建立副本，改個名做「82旅 舊資料備份」，再清原本嗰張。

## 之後點加旅團返去

**唔使改 Git，亦唔使起 `data/units/<編號>/` 資料夾。**
喺 Vercel → Settings → Environment Variables 加：

```
TROOP_0082_BACKEND = https://script.google.com/macros/s/AKfyc…/exec
TROOP_0082_APIKEY  = <你張 Sheet 嘅 API Key>
TROOP_0082_NAME    = 第八十二旅深資童軍團
```

再撳 **Redeploy**。你嘅旅團就會喺旅團選擇畫面出現，**由空白資料庫開始**，
之後你喺 app 入面輸入嘅嘢會直接寫入你自己張 Sheet。

API Key 由伺服器端（`api/proxy.js`）自動補上 —— **你唔使喺瀏覽器打任何 key 或者 `/exec` 網址**。

詳見 [`ADD_NEW_UNIT.md`](ADD_NEW_UNIT.md) 方法 B。
