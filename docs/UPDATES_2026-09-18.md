## 1. 點名：唔再「彈返上去頂」，改為「確定」先一次過傳後端

**症狀（團長回報）**：
- 撳一下點名掣，成頁彈返上去最頂，要自己㩒返落去，點一個彈一次。
- 每撳一下就即刻寫入後端（自動同步），冇「確定」掣 —— 想點晒全團先送一次都唔得。

**原因**：
- `calendar.js`（活動點名）同 `meetings.js`（會議出席點名）每粒掣 click 都會
  `update()` ＋ `refresh()` → 成個 app 重繪，`main.js` render 完就
  `window.scrollTo({ top: 0 })` → 所以彈上去頂。
- 每次 `update()` 都會 `persist()` → debounce 2.5 秒後推份資料庫去後端，
  即係「逐下嘈後端」。

**改法（兩個頁面一樣做法）**：
- 撳掣只記入**草稿**（`rollDraft` / `attDraft`），**只局部重繪點名嗰嚿**
  （`#rollPane` / `#attPane` innerHTML），唔會成頁重繪、唔會郁捲動位置。
- 再撳同一格＝還原嗰個位；「放棄改動」清空草稿。
- 新增右上**「確定點名」／「確定出席」**掣：撳先至 `update()` 一次過寫入
  （一次 persist ＝ 一次後端同步），toast 講明寫咗幾多項。
- 「全部出席」都變成暫存入草稿（會 toast 提醒要確定），唔會即刻寫入。
- 開另一個活動／會議會丟低未確定嘅草稿，唔會帶過去第二個。
- 頁面加咗提示字條：「撳掣點名唔會即刻寫入後端；點晒先撳確定，一次過儲存」。

**檔案**：`assets/js/views/calendar.js`、`assets/js/views/meetings.js`

## 2. 試卷：支援上載 Google Form 列印 PDF

**背景（團長講法）**：Google Form 冇得 OUTPUT CSV，但可以將問題 OUTPUT 成
PDF（表單右上 ⋮ →「列印」→ 另存 PDF）—— 咁就當佢係指定格式，由系統對上。

**改法**：
- 「試卷 → 匯入」分頁新增**「上載 Google Form PDF（或 .txt／.csv）」**掣。
- PDF **喺瀏覽器入面解析**（`assets/js/lib/pdftext.js`，**零依賴** —— 為咗
  唔引入成個 pdf.js，自己寫咗：
  inflate／deflate 解壓（RFC 1950/1951）、PDF 物件掃描（唔使 xref）、
  Type0 + Identity-H 字型嘅 ToUnicode 對照（bfchar／bfrange）、
  內容流 BT/Tf/Tm/Td/TJ 文字抽取連位置）。
- Google Form 列印 PDF 嘅版面好固定：題目喺左邊界、選項一律右移一段 ——
  就係靠呢個**縮排**分返「題目」同「選項」，單選／多選認唔出就當「單選」。
- 抽出嚟嘅文字會擺返落**可編輯**嘅文字格，下面有**即時預覽**（幾多題、
  每題類型＋選項），改完先撳「匯入成新試卷」—— 唔會收收埋埋抽錯仲匯入。
- 頁碼、「必填」星標、「提交」、「Google Forms」版尾等垃圾行會自動丟走。
- 順手修咗 CSV 類型：以前 `single` 呢個字根本認唔出（regex 冇包），一定變 short。

**測試**（`tests/pdftext.mjs`，純 Node 零依賴）：
- inflate：stored／fixed／dynamic／raw 四種 block 都解得返。
- 砌咗一份同 Chrome 列印一樣結構嘅中文 PDF（Type0 + Identity-H + ToUnicode +
  Flate 內容流、cm/q/Q、Tm/Td/TJ 連 kerning、WinAnsi literal string 連轉義括號）
  → 抽得出題目＋選項、x 縮排啱、行序啱 → parseQuizImport 出 3 題（2 單選＋1 短答）。
- 舊格式（人手貼「1. 題目」＋「A. 選項」、CSV、標題：）行為不變；
  「核取」關鍵字 → multi。

**限制（同埋點解無妨）**：
- 掃描圖片 PDF（冇文字層）讀唔到 —— 會明確報錯叫用家貼文字。
- 單選 vs 多選嘅圓圈／方格係圖形唔係文字，認唔出 → 預設單選，
  匯入後喺編輯器逐題改（預覽度有講明）。

**檔案**：`assets/js/lib/pdftext.js`（新）、`assets/js/views/quizzes.js`、`tests/pdftext.mjs`（新）

## 3. 進度紀錄：「成員進度」分頁數字同表格一致

**症狀（團長回報）**：成員進度表剔走咗管理員（唔會喺表度出現），
但上面「成員進度（N）」個標籤仲係計埋佢 —— 數字對唔上。

**原因**：分頁標籤用咗後端 raw `(remote.data.members || []).length`，
而表格用 `summarizeRemote()`（會剔走管理員／超管，同埋本系統嘅領袖）。

**改法**：分頁標籤改用 `summarizeRemote(...).memberCount` —— 標籤同表格永遠同一個數。

**檔案**：`assets/js/views/progress.js`
